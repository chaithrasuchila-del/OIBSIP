# 🧮 Calculator

## 📌 Project Description

This is a simple web-based calculator developed using HTML, CSS, and JavaScript. It performs basic mathematical calculations with a simple and user-friendly interface.

## 🎯 Objective

The main objective of this project is to create a functional calculator and improve my skills in web development and JavaScript programming.

## ✨ Features

* ➕ Addition

* ➖ Subtraction

* ✖️ Multiplication

* ➗ Division

* 🔄 Clear/Reset option

* 🔢 Number input

* 📱 Simple and responsive design

* 👩‍💻 Easy-to-use interface

## 🛠️ Technologies Used

* 🌐 HTML5 – Structure of the calculator

* 🎨 CSS3 – Styling and layout

* ⚙️ JavaScript – Calculator operations and functionality

## 📂 Project Structure

## 🔢 How It Works

1. 🔢 Enter numbers using the calculator buttons.

2. ➕ Select the required mathematical operation.

3. 🧮 Enter the second number.

4. 🟰 Click the "=" button to get the result.

5. 🔄 Use the clear button to reset the calculator.

## 📸 Project Output

The calculator provides a simple interface where users can perform basic mathematical calculations easily.

Through this project, I learned about HTML structure, CSS styling, JavaScript functions, user input, and basic web application development.
