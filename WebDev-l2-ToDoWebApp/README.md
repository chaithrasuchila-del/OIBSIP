# 📝 To-Do Web App

## 📌 Project Description

This is a simple web-based To-Do Web App developed using HTML, CSS, and JavaScript. It helps users add, manage, and track their daily tasks through a simple and user-friendly interface.

## 🎯 Objective

The main objective of this project is to create a functional To-Do Web App and improve my skills in web development, JavaScript programming, and task management.

## ✨ Features

* ➕ Add new tasks

* 📝 Manage daily tasks

* ✅ Mark tasks as completed

* 🗑️ Delete tasks

* 🔄 Clear completed tasks

* 📱 Simple and responsive design

* 👩‍💻 Easy-to-use interface

## 🛠️ Technologies Used

* 🌐 HTML5 – Structure of the To-Do Web App

* 🎨 CSS3 – Styling and layout

* ⚙️ JavaScript – Task management and functionality

## 📝 How It Works

1. ✏️ Enter a task in the input field.

2. ➕ Click the Add button to add the task.

3. 📋 View the added tasks in the task list.

4. ✅ Mark tasks as completed when finished.

5. 🗑️ Delete tasks that are no longer needed.

## 📸 Project Output

The To-Do Web App provides a simple and attractive interface where users can add, complete, and delete their daily tasks easily.

## 📚 Project Outcome

Through this project, I learned about HTML structure, CSS styling, JavaScript functions, event handling, and basic web application development.
